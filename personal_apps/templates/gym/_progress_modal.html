{# Quick per-exercise progress modal: PRs + recent history without leaving the page. Extracted from session_detail.html so exercise_detail.html (Task 12) can include the exact same component. Self-contained -- markup plus the behaviour that drives it. It fetches JSON (not HTML) from /gym/exercises//progress.json, so the response is injected with textContent-escaped values and nothing needs script-execution tricks. The chart is inline SVG built from `chart`, the geometry routes._chart_geometry computes -- the SAME numbers exercise_detail.html renders. It used to be Chart.js on a category axis, which drew a six-week gap and four same-day sessions at the same width, so the app's two charts disagreed about what x meant. The old comment here claimed the shared GymChart helper stopped them drifting; they had drifted on axis type, y-floor, record marking, deload marks and tick rendering anyway, because only the *drawing* was shared and none of the decisions were. Sharing the geometry instead of the renderer also drops the app's last external runtime dependency: 70 KB of Chart.js from a CDN, on the one screen that gets used in a gym basement. The SVG inherits the palette directly, its labels are HTML so they scale with text zoom, and CSS reduced-motion reaches it -- three things a canvas cannot do. #} {# A native , like every other modal in this app. This used to be a z-index div, and the comment here argued for that: a "would change the existing stacking and dismiss behaviour". That was true when it was written and became the reason the feature stopped working. The only control that opens this modal lives inside ``, which session_detail.html opens with showModal() -- the TOP LAYER, which beats every z-index and makes the rest of the document inert. So the modal removed its own `hidden`, painted underneath the sheet, and its close button could not take focus. Measured: elementFromPoint over the modal's own header returned `.sheet`, and document.activeElement never left the opener. showModal() also supplies, for free, everything the script below was hand-rolling: the focus trap, the scroll lock, Escape, the backdrop, and the aria-modal semantics. All of it is deleted rather than kept in parallel. #}
